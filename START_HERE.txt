🚀 HOW TO USE
═════════════════════════════════════════════════════════════════════════════

  1️⃣  Run Migration (First Time Only)
      $ node migrate.js
      ✅ DepartmentReports table created

  2️⃣  Start Server
      $ node index.js
      🔥 Server running on http://localhost:3000

  3️⃣  For Clients - Report Delayed Request
      • Login: client@geotrack.com / client123
      • Go to: My Requests page
      • Find: Pending request
      • Click: "📢 Report to Department" button
      • Select: Category → Department
      • Type: Reason for report
      • Click: Submit Report
      ✅ Report submitted!

  4️⃣  For Departments - View Reports
      • Visit: http://localhost:3000/department/DOH
      • See: Statistics dashboard
      • View: All incoming reports
      • Update: Report status (pending → received → in-progress → resolved)
      • Click: Update button
      ✅ Status updated!

🔐 SECURITY FEATURES
═════════════════════════════════════════════════════════════════════════════

  ✅ Authorization
     Users can only report their own requests
     Check: serviceRequest.userId === req.session.user.id

  ✅ Authentication
     Valid session required for report submission
     Check: req.session.user must exist

  ✅ Input Validation
     All fields validated server-side
     Department names verified against list
     Reason text sanitized

  ✅ Database Protection
     Foreign key constraints enforce integrity
     Sequelize prevents SQL injection
     Relationships properly established

  ✅ Error Handling
     Try-catch blocks on all routes
     Safe error messages (no data leaks)
     Proper HTTP status codes
